Skills Acquired After Completion

Participants will be able to:

  • Develop efficient JavaScript scripts in Google Earth Engine.

  • Access and process large satellite datasets (Landsat, Sentinel, MODIS, DEMs, etc.).

  • Build cloud-free image composites and preprocess imagery.

  • Generate vegetation, water, urban, and custom spectral indices.

  • Perform terrain analysis using DEMs.

  • Apply machine learning algorithms for land cover classification.

  • Evaluate model performance using accuracy assessment metrics.

  • Conduct multi-temporal change detection and time-series analysis.

  • Optimize GEE scripts for performance and scalability.

  • Export publication-ready maps and analysis outputs.

  • Design complete, reproducible remote sensing workflows suitable for research and industry applications.

Percentage Calculation

Use the following formula:

$$Percentage = ( Total Marks Obtained / 50 ) × 100 $$

Example

MCQ = 20/25

Practical = 22/25

Total = 42/50

Percentage

$$42 / 50 × 100 = 84\% $$

Pass Criteria

A candidate is declared PASS only if all of the following conditions are satisfied:

  • Overall Score: Minimum 25/50 (50%)

  • MCQ Score: Minimum 10/25 (40%)

  • Practical Score: Minimum 15/25 (60%)
