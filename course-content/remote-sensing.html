GRADING SYSTEM

For SpatialEdge Solutions Professional Certification, use the following grading system. It is simple, transparent, and suitable for certificates.

Examination Scheme

Component Maximum Marks
Online MCQ Examination 25
Practical Examination 25
Total 50

Percentage Calculation

Use the following formula:

$$Percentage = ( Marks Obtained / 50 ) × 100 $$

Example:

  • MCQ = 21/25

  • Practical = 19/25

  • Total = 40/50

Percentage:

$$40 / 50 × 100 = 80\% $$

Grade Calculation

Percentage Total Marks (Out of 50) Grade Performance
90–100% 45–50 A+ Outstanding
80–89.99% 40–44 A Excellent
70–79.99% 35–39 B+ Very Good
60–69.99% 30–34 B Good
50–59.99% 25–29 C Pass
Below 50% Below 25 F Fail

Pass Criteria

A candidate is declared PASS only if all of the following conditions are satisfied:

  • Overall Score: Minimum 25/50 (50%)

  • MCQ Score: Minimum 10/25 (40%)

  • Practical Score: Minimum 15/25 (60%)

This ensures candidates demonstrate both theoretical knowledge and practical competency.
